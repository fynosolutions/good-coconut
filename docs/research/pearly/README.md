# Pearly 调查：可迁移到 GOOD COCONUT 的优点

检查日期：2026-11-06（Asia/Shanghai）。来源：[Pearly 官网](https://drinkpearly.com/)。本次会话采用 Impeccable critique 独立设计评审与浏览器证据检查；未测试付款流程。

## 结论

Pearly 最值得借鉴的是包装、摄影、网页配色和波浪边界的一致性，以及“具体产品→制作过程→实拍→评论→行动”的阅读顺序。它是 DIY 奶茶套装电商，GOOD COCONUT 应借鉴信息组织，不照搬套餐、购物车和物流逻辑。

## 具体优点

| 维度 | 已观察的设计 | 可迁移原则 |
|---|---|---|
| 视觉 | 奶油白、蜜桃粉、浅紫背景和深紫字；橙粉摄影布景与包装协调 | 保留本站椰绿色盘，统一产品照片与页面背景的关系 |
| 布局 | 简洁导航，产品主视觉、短标题和明确购买按钮 | 让首屏同时说明品类与下一步 |
| 板块 | Best Sellers、三步制作、实拍、评论依次组织 | 在已有品类区域展示真实代表商品，不空泛重复品牌口号 |
| 排版 | 短标题与正文分工，商品卡信息结构一致 | 保留情绪标题，同时说明口味、质地和分类入口 |
| 图片 | 包装、杯体、奶液和珍珠同场拍摄 | 让产品的质地而非纯装饰成为主角 |
| 视频 | 首屏是JPG；下方三个方形自动循环静音制作视频，以及一个有控制条的竖屏视频 | 有真实视频再显示可播放控件；用动作解释制作和食用体验 |

## 不应照搬

原页面售罄提示与 ADD TO CART / Shop Now 并存，界面状态和操作承诺有冲突；本次没有交易验证，不推断其实际是否能购买。粗窄大写字适合短英文标题，不适合直接用于长中文正文。没有消费者族裔/性别购买占比数据，风格适配不是人口统计结论。

## 原始首页启发式评分

0–4高分更好，状态可见2、贴近用户语言4、一致性3、识别优于记忆3、审美与精简3，共15/20。用户控制、错误预防、效率、错误恢复、帮助未评估或不适用。分数不是转化率或无障碍评级。
