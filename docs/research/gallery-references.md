# Gallery 构图参考与采用范围

以下两项由用户明确指定纳入本次 PR。2026-11-06 已核对来源页面。它们解释 Gallery 的构图方向，并非网站生产图片来源。

## 1. 拍立得错落拼贴：看整体构图

[Memoria Visuals — About us](https://dribbble.com/shots/24764502-Memoria-Visuals-About-us)，作者 Miloš Vukadinović。来源描述为摄影工作室网站 About Us 区域的静态设计。

用户选定的借鉴方向：照片大小不一、轻微倾斜，白边下面放手写文字，围绕标题散开。这是本站 Gallery 的构图基础。

采用到本站：大小错落的照片框、轻微旋转、白色纸边、手写旁注与标题周围的非对称排列。桌面形成自由拼贴，手机重排为可浏览的双列。照片仍使用本站素材。

## 2. 美食 Ins 剪贴簿：看人物、食物和贴纸的混搭

[Aesthetic Foodie Scrapbook — Multi-photo Template](https://licowa.com/photo-collage/detail/aesthetic-foodie-scrapbook-polaroid-collage-template-10010248)，LiCoWa Design，来源标注2025-03-24。用户原始链接：https://www.licowa.net/photo-collage/aesthetic-foodie-scrapbook-polaroid-collage-template-10010248 ，当前重定向至上方地址。

用户选定的借鉴方向：真人吃东西的照片、饮品特写、食物抠图叠在一起，内容有重叠、有生活感；这张参考的氛围最接近目标。它是平面拼贴模板，不是完整网站交互示范。

采用到本站：食物和店内照片、彩色纸胶带、品牌贴纸、手写便签混搭；有重叠和错位，但文字和操作入口保持可读。手机布局与图片弹层由本站独立实现，不把静态模板当作现成交互规范。

## 本轮边界

- 保留原产品照片带，新 Gallery 位于照片带之后、门店之前。
- 保留两排八张新增照片以及原 Gallery 照片与三个竖版封面，不替换相邻重复素材。
- 三个视频位为待补内容，移除播放图标并明确显示 Video coming soon；未添加虚构达人、用户评价或播放量。
- 参考站、Dribbble 和 LiCoWa 的照片、人物与模板素材均未复制进本站生产资源。
- 后续有真实、可用的视频或生活方式素材时，再更新对应素材。当前 PR 交付的是完整拼贴实现与诚实的待上线视频状态。
